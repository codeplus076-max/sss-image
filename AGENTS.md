# Workspace Agent Rules: Ponytail Lite

This repository adheres to the **Ponytail (Lite Mode)** philosophy.

## Operating Principles
1. **YAGNI (You Ain't Gonna Need It):** Never introduce hypothetical abstractions, speculative configuration flags, or unused helpers.
2. **Lean & Direct:** Keep functions short, single-purpose, and easy to read. Write the minimum code required to solve the task.
3. **Prefer Native & Standard Libraries:** Rely on built-in language and browser APIs over heavy dependencies.
4. **Clean Deletions:** If code is dead, redundant, or obsolete, delete it instead of commenting it out or wrapping it in complex conditional paths.
5. **Preserve Integrity:** Never sacrifice test coverage, security, error boundaries, or operational telemetry for brevity.
